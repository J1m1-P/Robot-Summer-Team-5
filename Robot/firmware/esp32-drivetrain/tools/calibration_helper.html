MoveS/RotS Calibration Helper

Computes F_lon, F_lat, and F_ang from trial measurements per Tu & Min (2019), "Calibration Method of Mecanum Wheeled Mobile Robot Odometer" (misc/Calibration_Method_of_Mecanum_Wheeled_Mobile_Robot_Odometer.pdf). Run trials with src/harnesses/calibration_main.cpp ([env:calibration]), physically measure each trial's result, enter the numbers below. Nothing here talks to the robot -- it's a standalone calculator. All math runs locally in this page.

Robot geometry

Matches XDriveKinematicsConfig in src/config/drivetrain/drivetrain_config.c -- defaults below are that file's current values. Update here if the config changes; this page doesn't read it automatically.

1. Straight-line trials

F_lon & F_lat

Command move <L1> 0 <speed> on the calibration harness. Before each run, mark the robot's start position and heading (a line off the front). After it stops, tape-measure x_e (longitudinal shortfall from L1) and y_e (lateral drift), and separately protractor-measure θ_e (heading drift from the marked starting heading -- a direct reading, not derived from x_e/y_e). Enter one row per trial; more trials average out measurement noise.

# x_e (mm) y_e (mm) θ_e (deg)

2. In-place rotation trials

F_ang

A separate experiment from the straight-line trials above -- does not reuse that data. Command rotate <angle> <max_omega>, protractor-measure the robot's actual rotation against the commanded angle. Enter one row per trial.

# θ1 commanded (deg) θ2 actual (deg)

3. Radial error validation (optional)

δr_e / δr_m

Once F_lon/F_lat/F_ang are applied, re-run straight-line trials and record the new endpoint error to confirm the correction actually helped -- paper eq. 24-25. "Before" rows can reuse the x_e/y_e values from section 1; "after" rows come from a fresh round of trials with the correction factors applied.
