Motor toggles send "motor <n> <0|1>\n"; each gain/target field sends its matching command (e.g. "ff 0.5\n") — all over the same serial link used for telemetry, shared across every enabled motor. Values live in RAM on the board only — copy final ff/ffo/kp/ki into config/drivetrain/drivetrain_config.c by hand once you're happy. The gain fields above default to that file's current compiled-in values, but they never auto-sync from the board (e.g. after someone else's tuning session, or a reconnect) — click "Show current gains" first and check the log before trusting an untouched field.
